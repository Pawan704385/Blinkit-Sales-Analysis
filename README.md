# 📊 Blinkit Sales Analysis – Power BI Project

### 📝 Overview
This Power BI project provides a **comprehensive analysis** of Blinkit's sales performance, customer satisfaction, and inventory distribution. The dashboard utilizes key **KPIs, charts, and visualizations** to identify insights and opportunities for optimization. This project was created for **practice and learning purposes** only.

### 📌 Business Objective
The main goal of this project is to **analyze sales data** to improve decision-making by:
- Understanding total sales performance
- Evaluating customer satisfaction
- Identifying trends in inventory and outlet performance

### 📈 Key KPIs Used
- **Total Sales:** Overall revenue generated from items sold.
- **Average Sales:** Revenue per sale.
- **Number of Items:** Total count of different items sold.
- **Average Rating:** Customer rating for items sold.

### 🔍 Data Analysis Process
1. **Requirement Gathering:** Understanding business needs.
2. **Data Walkthrough:** Exploring dataset contents.
3. **Data Connection:** Connecting Power BI with the data source.
4. **Data Cleaning & Quality Check:** Ensuring accuracy and consistency.
5. **Data Modeling:** Creating relationships between tables.
6. **Data Processing:** Preparing data for visualizations.
7. **DAX Calculations:** Using Power BI’s Data Analysis Expressions for insights.
8. **Dashboard Layouting & Charts:** Designing interactive visuals.
9. **Insights Generation:** Extracting meaningful business insights.

### 📈 Key Visualizations
| Visualization Type | Purpose |
|-------------------|---------|
| **Donut Chart** | Analyzing total sales by fat content |
| **Bar Chart** | Identifying best-performing item types |
| **Stacked Column Chart** | Comparing total sales across outlets |
| **Line Chart** | Evaluating outlet establishment impact on sales |
| **Pie Chart** | Analyzing sales by outlet size |
| **Funnel Map** | Understanding geographic sales distribution |
| **Matrix Card** | Displaying all key metrics by outlet type |

### 📌 Insights Extracted
- **Tier 3 outlets** contribute the highest sales.
- **Supermarket Type 1** has the highest total sales.
- **Medium-sized outlets** generate the most revenue.
- **Items like Fruits & Snacks** perform better in terms of revenue.

### 🔧 How to Use This Project
#### Prerequisites:
- **Power BI Desktop** installed

#### Steps to View the Dashboard:
1. **Download the `.pbix` file** from this repository.
2. **Open Power BI Desktop** and load the file.
3. **Explore the dashboard** and interact with filters to gain insights.
4. Modify **DAX measures** or create new visualizations as needed.
